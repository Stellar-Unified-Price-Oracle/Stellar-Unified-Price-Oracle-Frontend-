# Independent Price Proof Verification Guide

This document describes how exported price proof bundles generated by the Stellar Unified Price Oracle frontend can be independently validated and verified without trusting the web application or centralized servers.

## Proof Bundle Structure

When a user exports a proof from the **Proof** tab (`PriceProofPanel`), the system generates a standalone JSON artifact with the following schema:

```json
{
  "proof": {
    "record": {
      "assetPair": "XLM/USD",
      "price": 0.12,
      "priceScaled": "1200000",
      "priceDecimals": 7,
      "timestamp": 1700000000000,
      "confidence": 0.95,
      "sources": ["chainlink", "reflector"],
      "version": 5
    },
    "contributions": [
      {
        "source": "chainlink",
        "price": 0.1199,
        "timestamp": 1699999999000,
        "signature": "...",
        "publicKey": "..."
      }
    ],
    "aggregateSignature": "...",
    "contractId": "CB...",
    "ledgerSequence": 987654,
    "transactionHash": "...",
    "network": "testnet"
  },
  "verification": {
    "version": "1.0.0",
    "description": "Independent verification bundle for Stellar Unified Price Oracle on-chain proof",
    "exportedAt": "2026-10-19T22:00:00.000Z",
    "contractId": "CB...",
    "network": "testnet",
    "ledgerSequence": 987654,
    "transactionHash": "...",
    "cliCommand": "soroban contract invoke --id CB... --network testnet -- get_proof --asset_pair XLM/USD --at_timestamp 1700000000000",
    "verificationSteps": [ ... ]
  }
}
```

## Step-by-Step Verification Procedure

### 1. Ledger Finality & Transaction Anchor
Verify that the transaction hash is anchored on the designated Stellar network at the specified ledger sequence.

- **Stellar Expert**: `https://stellar.expert/explorer/<network>/tx/<transactionHash>`
- **Horizon / Soroban RPC**:
  ```bash
  curl -s "https://horizon-testnet.stellar.org/transactions/<transactionHash>" | jq '{successful: .successful, ledger: .ledger}'
  ```

### 2. Querying the Soroban Smart Contract Directly
Execute the contract invocation method directly using the official `soroban` CLI or `stellar` CLI:

```bash
soroban contract invoke \
  --id <contractId> \
  --network <network> \
  -- get_proof \
  --asset_pair <assetPair> \
  --at_timestamp <timestamp>
```

This reads contract instance storage directly from RPC nodes without intermediate aggregators or web services.

### 3. Cryptographic Signature Verification
Each contributing source signs its individual price tick:
- Message payload: canonical serialization of `(source, priceScaled, timestamp)`.
- Keypair: Ed25519 public key (`publicKey`).
- Signature: Ed25519 signature (`signature`).

The aggregate signature commits to the root hash of the contributing ticks and the calculated median price, signed by the oracle contract publisher or multi-party threshold keys.

### 4. Consensus & Confidence Bounds
The contract verifies:
- Minimum quorum threshold of active oracle sources.
- Sorting contributing prices to compute the median price.
- Dynamic confidence interval calculated from dispersion and variance across contributing sources.
